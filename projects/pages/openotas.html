opeNotas

Aplicación para tomar notas y apuntes en clase, pensada para capturar ideas con rapidez y mantener el material académico organizado.

1 / 3

Visión general

opeNotas nace como herramienta personal para el día a día en clase: crear, editar y revisar apuntes sin fricción, priorizando una interfaz clara y usable.

El foco está en el flujo de escritura y la organización del contenido, con un stack web en JavaScript orientado a iterar rápido sobre la experiencia de usuario.

Aspectos clave

  • Captura rápida de notas orientada a contexto académico
  • Interfaz web pensada para uso frecuente en clase
  • Código abierto en GitHub para evolución continua
