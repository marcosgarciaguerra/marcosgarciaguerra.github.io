PROYECTO #3 · TypeScript

Games_web / MesaPlay

Colección de juegos web en TypeScript, desplegada en Vercel bajo la marca MesaPlay para probar la experiencia en vivo.

1 / 3

Visión general

Games_web agrupa experiencias de juego ligeras en el navegador. El objetivo es practicar UI tipada, interacción y despliegue continuo en un entorno real.

La demo pública en Vercel (MesaPlay) permite validar el producto sin instalar nada: abre, juega y comparte el enlace.

Aspectos clave

  • Juegos web con TypeScript
  • Despliegue en Vercel con URL pública
  • Repositorio abierto para consultar el código
